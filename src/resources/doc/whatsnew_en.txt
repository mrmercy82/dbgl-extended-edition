DBGL Extended Edition - New features since DBGL 0.100 beta 17
=============================================================

DBGL was developed up to version 0.100 beta 17 by Ronald Blankendaal
(https://dbgl.org; announcement of 0.100 beta 17:
https://www.vogons.org/viewtopic.php?p=1380082#p1380082). The Extended Edition
is an independent continuation he is not involved in. It mainly adds support
for current DOSBox versions; the foundation and a large part of it are his
work, the result of nearly 20 years of development.

Profiles, database and settings are kept when switching.

Extended Edition (source code, downloads, reporting problems):
https://github.com/mrmercy82/dbgl-extended-edition


IMPORTANT: JAVA 21 IS NEEDED
----------------------------
  From 0.101 alpha 51 on, DBGL Extended Edition needs Java 21 or newer and
  does not open with an older Java any more; it then shows a window that
  says which Java was found. Java 21 is available e.g. as Eclipse Temurin:
  https://adoptium.net/temurin/releases/?version=21
  Please update Java before the update. The stand-alone package for Windows
  brings Java 21 along (from 0.101 alpha 52 on).


NEWEST IN 0.101 ALPHA 53
------------------------
  - One import from a folder instead of two: known games are recognized by
    their files (also games learned from your own profiles), every further
    game folder with a DOS program is added, with titles from its text
    files. All imports are in the submenu "Import".
  - "Complete profiles...": titles, details and covers in one go, with a
    traffic light per profile; also as a page of the welcome wizard.
  - "Manage learned games...": view, change and forget the games learned
    from profiles.
  - Check: Windows 3.x and 95/98 in a profile (what Windows starts, sound
    driver, S3 driver, missing programs); "Programs of Windows 3.x as
    profiles...".
  - Check: what DOSBox wrote at the last start, notes from DBConf and from
    eXoDOS for comparison, export for the developer.
  - Statistics with new sections and a year in review; a welcome wizard at
    the first start.
  - Taken over from DBGL 0.100 beta 18 by Ronald Blankendaal: the DBConf
    database that comes with DBGL (made by him and allowed for the Extended
    Edition) and cutting values that are too long when saving.


NEWEST IN 0.101 ALPHA 52
------------------------
  - Saved games: the backups are in a folder of their own
    (savegames\<number>); existing ones are copied and checked at the first
    start, the old ones stay. Backups can be named and kept, and before the
    start DBGL shows which state is in the game folder and lets you start
    with another backup (also in TV mode). "Saved games..." in the context
    menu of a profile; deleting a profile keeps its backups by default.
  - Second backup place, e.g. OneDrive or Dropbox; the automatic backup can
    include screenshots and backups of saved games.
  - ScummVM games as profiles (import from scummvm.ini, start with play
    time, screenshots, online lookup, a lean profile editor of their own).
  - LaunchBox: import your own MS-DOS collection; add profiles to LaunchBox.
  - RAWG as another source of online info; Steam pictures from SteamGridDB.
  - TV mode: "Recently played", info with all pictures of a game.
  - Screenshots on the right above the description; shader preview; the
    next part of a game series offered after playing.
  - Find sound files (SoundFonts, MT-32 and Sound Canvas ROMs, Ultrasound
    patches); import games that have no profile yet from a folder.
  - The stand-alone package for Windows comes with Java 21 (and once
    without Java).


NEWEST IN 0.101 ALPHA 51
------------------------
  - Java 21 is needed now (see above).
  - Stand-alone packages for Windows, Linux and macOS: DBGL Extended
    Edition can now be installed without DBGL 0.100 beta 17; on Windows
    and macOS DOSBox 0.74-3 comes with it.
  - New launch.exe: finds Java 21 also through JAVA_HOME and the PATH.
  - "Take pictures of all windows (for error reports)" in the window
    "Manage log files" (menu File).
  - New libraries for the user interface (SWT 4.41, Nebula Gallery 1.1.0).
  - Fixed: the error "create initial tables" after the new start for a
    switch to dark mode; messages that disappeared behind other windows.


NEWEST IN 0.101 ALPHA 50
------------------------
  - Bring back from the USB stick: play time, saved games and screenshots
    come back into the installation, with a preview per game in which you
    tick what is taken over.
  - "Check profiles" finds more: sound settings that do not fit together,
    other values in the setup of the game, CD images that are not used,
    hints for single games.
  - Wizard and batch files: a better choice of the program to start and
    of the setup program, far fewer false alarms for batch files.
  - DOSBox versions: recognized from DOSBox 0.62 on, configuration files
    in other languages, taking over from DOSBox 0.74 to DOSBox Staging
    converts the values, a notice and a report for a version DBGL does
    not know yet.
  - Large collections: with thousands of profiles the table is there much
    faster.
  - "Manage log files"; creating and restoring a backup in the window
    "Manage backups".
  - Tab "Without pictures" for profiles without cover and screenshot; the
    context menus are in a new order.
  - Fixed: the D-Fend import in dark mode under Windows, the DOSBox log
    window freezing.


NEWEST IN 0.101 ALPHA 49
------------------------
  - DOSBox Staging 0.83.1 is supported; the value "auto" for keyboard and
    country, which is gone there, is recognized and explained.
  - Take over settings from another DOSBox configuration: your own
    settings of the old file into the new one, with a preview.
  - Switching profiles to another DOSBox version: a preview in the profile
    editor too, inherited values per profile, comparing two versions, a
    message when it is done that points to "Undo".
  - Game series: the profiles of a series belong together, in the list and
    as a stack in TV mode.
  - Quick search (F3) and the new column "Disk space".
  - "Manage backups": all backups in one list, to lock, delete and
    restore.
  - "Download DOSBox": one window with all versions and the folder they
    go to.
  - "Check profiles": files without a profile, a hint on the mouse for
    Windows 95 in DOSBox-X; warning signs in the tile and box views too.
  - Reports saved as text, as a web page in color or as PDF.
  - Every setting explains itself in a tooltip; the dark mode improved
    further.
  - A tidier main folder: texts in "docs", logs in "logs", the cache in
    "cache".


NEWEST IN 0.101 ALPHA 48
------------------------
  - TV mode (F11): your games as big covers full screen, with the keyboard
    or a controller (XInput on Windows, joystick on Linux).
  - Add to Steam: profiles as non-Steam games, with cover and play time
    through DBGL.
  - USB stick: an assistant packs DBGL with the chosen profiles, games and
    DOSBox versions portable into a ZIP file.
  - Saved games are backed up before each start and restored with a click;
    DOSBox-X saved states per game.
  - Import of eXoDOS games and DFendX game archives.
  - Dark mode reworked, "As the system", new mode "High contrast".
  - Customizable toolbar: buttons, order, separators.
  - Controller as keyboard, differences from the defaults in the context
    menu, F1 lists all shortcuts.


NEWEST IN 0.101 ALPHA 47
------------------------
  - Saving leaves a profile file as it was; only what was changed is
    changed. Long start scripts stay intact in the profile editor.
  - Profile editor: OK and Cancel without waiting.
  - MT-32 and Sound Canvas ROMs are recognised by their checksums.
  - "Check profiles": a missing ULTRASND folder can be solved with one click.
  - After an update: keep or delete the installation file.


NEWEST IN 0.101 ALPHA 46
------------------------
  - Saving a profile works much more reliably.
  - "Check profiles" finds much more (syntax errors, duplicate settings,
    values out of range, unknown commands, order of drives and more), each
    with a solution to choose and a preview; with a progress bar and
    sorting.
  - "Restore an earlier version..." with the original before DBGL first
    changed it; "Undo" for changes of many profiles.
  - Profile editor: which MT-32 and Sound Canvas ROMs and GUS patch files
    DOSBox finds.
  - A backup of your choice before an update of the Extended Edition.


NEWEST IN 0.101 ALPHA 45
------------------------
  - Get covers for many profiles at once, from all online sources, with a
    preview to tick; ScreenScraper is enabled.
  - One-click update of the Extended Edition (download, checksum, backup,
    restart; usable from alpha 46 on).
  - "Check profiles" recommends DOSBox-X where needed and switches with one
    button.
  - Statistics also as HTML with bar charts or as CSV.
  - Random game by choice (never started, favorites, most or least played);
    play time and sessions for every profile; last DOSBox log in the
    context menu.
  - Long links (up to 2048 characters) are saved (database 0.103, still
    readable by DBGL 0.100 beta 17).


NEWEST IN 0.101 ALPHA 44
------------------------
  - Import GOG and Steam games, recommending DOSBox-X where needed.
  - Find and merge duplicate profiles.
  - Statistics with play sessions, play time by year and month, counts by
    version, genre, developer and year of release; can be saved as a
    report.
  - Toolbar with filter, online info, check profiles, random game,

  - DOSBox output as a log per profile; warning for PC-98 images without

NEWEST IN 0.101 ALPHA 42 AND 43
-------------------------------
  - Replace values in many profiles at once, with preview and a choice of

  - Find manuals, walkthroughs, maps, reference cards, copy protection and

  - Game information from IGDB, SteamGridDB and MobyGames (official API).

  - View buttons List / Tiles / Boxes and a "View" menu; faster start.


MAJOR NEW FEATURES
------------------

1. Full support for DOSBox Staging 0.83
   Renamed settings (e.g. glshader -> shader) and on/off switches are
   converted automatically. Every setting has its own field: CRT colour
   profile, deinterlacing, dedithering, image adjustments, Sound Canvas,
   denoiser, drive noises and more.

2. DOSBox-X up to 2026.10.01
   About 100 common settings have real fields ("Additional options"). The
   configuration is generated completely; in 0.100 beta 17 about half of the
   settings were missing.

3. Every setting of every DOSBox version is reachable
   Settings without a field of their own sit on the matching page in a
   collapsible "Further settings" group: with description, list of values,
   bold for changed values and a reset button.

4. The profile dialog adapts to the DOSBox version
   Option lists come from the configuration of the installed DOSBox. Empty
   pages disappear. The search finds descriptions and values too.

5. Download DOSBox directly
   DOSBox -> "Download DOSBox...": get Staging or DOSBox-X from GitHub (with
   checksum, cancellable, choice of build), unpack it into a folder of your
   choice, add it as a DOSBox version and switch profiles.


MORE NEW FEATURES
-----------------

Keeping profiles in shape
  - Check profiles: find and repair invalid values, missing folders and files,
    fix moved paths for all profiles at once.
  - Warning sign in the profile list with tooltip; a click jumps to the
    setting. "With problems" tab, context menu "Fix problems...".
  - Earlier versions: the last ten configurations of every profile.
  - Compare profiles, statistics (play time, most played games).

Many profiles at once
  - Presets (Windows 95/98, Windows 3.1, slow and fast games, Tandy, PC-98,
    your own), also for all selected profiles.
  - Switch to another DOSBox version, with preview, report and a comparison
    of both versions. Whatever would be dropped, including lines added by
    hand to the [autoexec], can be kept line by line.
  - Edit several profiles, including the further settings.
  - Undo the last change of several profiles.
  - Replace values, e.g. output=surface by texture in all selected profiles,
    with a preview and a choice of the possible values.
  - Find manuals, walkthroughs, maps, reference cards, copy protection and
    soundtracks in the game folder and link them in the profile.

Safety and comfort
  - Create and restore backups, optionally automatic.
  - Status window with DOSBox output, errors highlighted, messages clickable.
  - Drop a dosbox.conf on a profile to take over its settings.
  - Lines added by hand to the [autoexec] are no longer lost: kept
    automatically (with or without DBGL's @REM lines) or chosen line by line,
    see Settings -> General.
  - PC-98: browse, start and boot hard disk and floppy images.
  - Remove unused DOSBox versions together with their folder (with a double
    safety question).


SMALLER IMPROVEMENTS
--------------------
  - Play time per game, as a sortable column.
  - German complete, about 7,000 more texts translated in 17 languages.
  - Tooltips stay while the mouse is over them (can be turned off).
  - "Differences from defaults..." for every profile.
  - Check of folders, images and values before starting.
  - Version check at startup, configuration rewritten when needed.
  - Optional notice of new versions of the Extended Edition, pre-releases
    included (Settings -> General, Help -> "Check for updates...").
  - Newer DOSBox versions DBGL does not know yet are mapped correctly.
  - Shader lists with your own shaders, "Sound Blaster 2" page.
  - Help -> "New features..." and "Changelog...".
  - Failed boot: the DOSBox message stays visible.
  - View as list, tiles (with screenshot) or boxes (with cover art): buttons
    at the top right or the "View" menu (Ctrl+1 to Ctrl+7).
  - Game information also from IGDB and SteamGridDB, MobyGames through its
    official API; searching with a Cancel button and understandable errors.
  - Several CDs: CD2, CD3 ... are offered as well; CD images are mounted the
    right way for each DOSBox version (mount or imgmount).
  - Icons for links and the profile configuration in the context menu "View".
  - Shader presets of DOSBox Staging 0.83, refresh shaders, try run.
  - Optionally all DOSBox settings in the profile (as D-Fend Reloaded does).


BUG FIXES COMPARED TO 0.100 BETA 17
-----------------------------------
  - DOSBox-X 2024.10.01 and later: the configuration held only about half of
    the settings.
  - Paths with spaces work (8.3 short names as in DOSBox).
  - Empty entries overrode DOSBox defaults.
  - Boot lines with a Windows path created a broken mount.
  - Assigning another DOSBox version took over old defaults.
  - Reader for older DOSBox configurations fixed.
