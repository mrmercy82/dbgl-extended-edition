DBGL Extended Edition 0.101 alpha @N@
====================================

Unofficial, independent continuation of DBGL 0.100 beta 17 by
Ronald Blankendaal (https://dbgl.org), who is not involved in it.
Inoffizielle, unabhaengige Weiterfuehrung von DBGL 0.100 beta 17 von
Ronald Blankendaal (https://dbgl.org), der daran nicht beteiligt ist.

update\    Unzip over an existing DBGL 0.92 to 0.100 beta 17 or an earlier
           DBGL Extended Edition 0.101 alpha (copy the DBGL folder and all
           DOSBox folders first). See update-readme.txt.
           Ueber eine bestehende Installation von DBGL 0.92 bis 0.100 beta 17
           oder eine fruehere DBGL Extended Edition 0.101 alpha entpacken
           (vorher den DBGL-Ordner und alle DOSBox-Ordner kopieren).
           Siehe update-readme.txt.
source\    Complete source code (GPL) and patch against 0.100 beta 17.
           Vollstaendiger Quellcode (GPL) und Patch gegen 0.100 beta 17.
COPYING.txt  GNU General Public License version 2.

Java 21 or newer is needed / Java 21 oder neuer ist noetig:
https://adoptium.net/temurin/releases/?version=21

No DBGL yet? Take the stand-alone package for your system instead
(DBGL-Extended-Edition-0.101alpha@N@-windows.zip with Java,
-windows-without-java.zip, -linux.tar.xz, -macos-x86.tar.gz or
-macos-arm.tar.gz); it needs no other DBGL.
Noch kein DBGL? Stattdessen das eigenstaendige Paket fuer das eigene
System nehmen (DBGL-Extended-Edition-0.101alpha@N@-windows.zip mit Java,
-windows-without-java.zip, -linux.tar.xz, -macos-x86.tar.gz oder
-macos-arm.tar.gz); es braucht kein anderes DBGL.
