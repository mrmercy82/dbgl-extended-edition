DBGL 0.101 alpha @N@ - Extended Edition
======================================

Builds on DBGL 0.100 beta 17 by Ronald Blankendaal (https://dbgl.org).
This is an alpha: back up your DBGL folder and your DOSBox folders first.


NEW INSTALLATION (no DBGL yet)

Do not use this archive. Take the stand-alone package for your system from
https://github.com/mrmercy82/dbgl-extended-edition/releases
  Windows  ...-windows.zip               (Java included)
           ...-windows-without-java.zip  (for a Java 21 you have already)
  Linux    ...-linux.tar.xz
  macOS    ...-macos-...tar.gz
Unzip it into a folder of its own and start launch.exe (Windows), dbgl
(Linux) or DBGL.app (macOS). Linux and macOS need Java 21:
https://adoptium.net/temurin/releases/?version=21


UPDATE (DBGL 0.92 to 0.100 beta 17, or an earlier DBGL Extended Edition alpha)

1. Close DBGL. Java 21 must be installed (or come with the Windows package).
2. Unzip this archive into your DBGL folder and replace existing files.
3. Start DBGL. Profiles, database and settings are kept.

From 0.101 alpha 46 on, Help > "Check for updates of the DBGL Extended
Edition..." does this by itself. DBGL older than 0.92: update it to the
official DBGL 0.92 first and start it once.

In this archive: dbgl.jar, launch.exe (Windows), lib, plugins, docs, db
(the DBConf database, from 0.101 alpha 53 on) and update-readme.txt (this
file, in the main folder of DBGL).

DBGL 0.101 alpha @N@ - Extended Edition
======================================

Baut auf DBGL 0.100 beta 17 von Ronald Blankendaal auf (https://dbgl.org).
Dies ist eine Alpha: vorher den DBGL-Ordner und die DOSBox-Ordner sichern.


NEUINSTALLATION (noch kein DBGL)

Dieses Archiv nicht verwenden, sondern das eigenstaendige Paket fuer das
eigene System von
https://github.com/mrmercy82/dbgl-extended-edition/releases
  Windows  ...-windows.zip               (mit Java)
           ...-windows-without-java.zip  (fuer ein vorhandenes Java 21)
  Linux    ...-linux.tar.xz
  macOS    ...-macos-...tar.gz
In einen eigenen Ordner entpacken und launch.exe (Windows), dbgl (Linux)
oder DBGL.app (macOS) starten. Linux und macOS brauchen Java 21:
https://adoptium.net/temurin/releases/?version=21


UPDATE (DBGL 0.92 bis 0.100 beta 17 oder eine fruehere Alpha der DBGL Extended Edition)

1. DBGL schliessen. Java 21 muss installiert sein (oder im Windows-Paket
   mitgekommen sein).
2. Dieses Archiv in den DBGL-Ordner entpacken, vorhandene Dateien ersetzen.
3. DBGL starten. Profile, Datenbank und Einstellungen bleiben erhalten.

Ab 0.101 alpha 46 erledigt das Hilfe > "Nach Updates der DBGL Extended
Edition suchen..." von selbst. DBGL aelter als 0.92: zuerst auf das
offizielle DBGL 0.92 aktualisieren und einmal starten.

In diesem Archiv: dbgl.jar, launch.exe (Windows), lib, plugins, docs, db
(die DBConf-Datenbank, ab 0.101 alpha 53) und update-readme.txt (diese
Datei, im Hauptordner von DBGL).
