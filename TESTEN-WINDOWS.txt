DBGL Extended Edition - Testliste für Windows
=============================================

Entwickelt und automatisch getestet wird unter Linux. Unter Windows verhalten
sich Fenster-Layout (SWT), Pfade, Laufwerksbuchstaben und das Starten von
DOSBox teilweise anders. Diese Liste in 20 bis 30 Minuten durchgehen und bei
jedem Punkt notieren: OK, oder was passiert ist (am besten mit Bildschirmfoto).

Vorher: Menü -> Sicherung erstellen...


1. Start und Hauptfenster
   [ ] DBGL startet, Fenstertitel endet mit "- Extended Edition".
   [ ] Hilfe -> Über: Ronald Blankendaal als Autor, darunter der Hinweis zur
       Extended Edition, ganz klein "begonnen von mrmercy82 mit Hilfe von KI".
   [ ] Profile mit Fehlern haben ein Warnsymbol vor dem Titel. Maus darauf:
       Tooltip mit den Problemen. Klick darauf: Profildialog an der Stelle.
   [ ] Reiter "Mit Problemen" (rechts neben den eigenen Filtern) zeigt nur
       diese Profile.
   [ ] Rechtsklick auf ein Profil mit Warnsymbol -> "Problem beheben..." ist
       aktiv, bei anderen Profilen ausgegraut.

2. Einstellungen
   [ ] Menü -> Einstellungen -> Allgemein: Fenster kleiner ziehen, es
       erscheint eine Bildlaufleiste, alle Gruppen bis "DBGL-Spracheinstellungen"
       sind erreichbar.

3. DOSBox-Versionen
   [ ] DOSBox -> DOSBox herunterladen...: DOSBox Staging (und DOSBox-X)
       werden angeboten. "Ja" lädt herunter, entpackt in den DOSBox-Ordner von
       DBGL und öffnet den Dialog der DOSBox-Version. OK legt die
       Konfigurationsdatei an (DOSBox-Fenster blitzt kurz auf, das ist normal).
   [ ] Danach die Frage, ob Profile umgestellt werden sollen.
   [ ] Knopf "Erkennen" bei DOSBox 0.74, ECE, Daum, SVN: Version wird
       erkannt, ohne dass ein DOSBox-Fenster aufgeht.

4. Profildialog
   [ ] DOSBox-X-Profil: Seiten Speicher, CPU, Video, VESA / SVGA, Maus,
       Sound Blaster, DOS: Gruppe "Zusätzliche Optionen" ist vollständig
       sichtbar, nichts überlappt, Tooltips zeigen den DOSBox-Hilfetext.
   [ ] Zweites Öffnen eines Profils (auch nach DBGL-Neustart) geht schnell.
   [ ] Knopf "Voreinstellungen" -> eigene speichern, -> Bearbeiten (Name und
       Text ändern), -> Löschen.

5. Mehrere Profile
   [ ] Zwei oder mehr Profile markieren -> Rechtsklick -> Voreinstellung
       anwenden.
   [ ] Danach Profile -> "Letzte Änderung mehrerer Profile rückgängig...":
       die Profile sind wieder wie vorher.
   [ ] Dasselbe nach "Profil auf andere DOSBox-Version umstellen..." mit
       mehreren Profilen: auch die DOSBox-Version kommt zurück.
   [ ] Mehrere Profile bearbeiten: weitere Einstellungen werden angezeigt,
       unterschiedliche Werte rot markiert.

6. Pfade und Laufwerke
   [ ] Profil mit Laufwerk auf einem anderen Laufwerksbuchstaben (z. B. D:\Spiele)
       startet. Nach Verschieben des Ordners: Profile prüfen -> Pfade reparieren.
   [ ] Pfade mit Leerzeichen und Umlauten (z. B. "C:\Spiele\Die Siedler")
       funktionieren beim Starten und beim Herunterladen von DOSBox.

7. Sprache
   [ ] Einstellungen -> Anzeigesprache auf eine andere Sprache stellen (z. B.
       Français), DBGL neu starten: Menüs und Profildialog sind übersetzt,
       nichts ist abgeschnitten.
